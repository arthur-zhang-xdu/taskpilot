### B. 数据契约

推荐字段如下，具体映射服从 Day 1 实际数据：

| 字段 | 建议类型 / 约束 | 含义 |
|---|---|---|
| `incident_id` | 非空字符串，主键或唯一约束 | 合成故障唯一标识 |
| `service` | 非空字符串 | 服务名称 |
| `occurred_at` | 带时区时间戳 | 故障发生时刻 |
| `error_type` | 非空字符串 | 错误类别 |
| `severity` | 有限取值字符串 | 等级，取值以实际数据为准 |
| `message` | 文本 | 模拟错误描述 |
| `resolution` | 可空文本 | 模拟处理记录 |

规则：

- 使用 Pydantic 或现有校验机制验证导入输入，数据库保留必要的非空、唯一与检查约束。
- 不新增与业务无关的复杂实体关系。
- 保留合成数据标记，不能写成真实企业事故。
- PostgreSQL 使用 `TIMESTAMP WITH TIME ZONE` 等价映射；应用统一以 UTC 处理存储与比较，展示可转换为 Asia/Shanghai。数据库不保存原始时区名称，若确需保留应额外建字段，Day 3 通常无需。
- 拒绝不带时区的时间，或沿用已有明确且有测试的转换策略，不依赖服务器默认时区猜测。
- 查询统一 `[start_time, end_time)`，起点包含、终点排除；开始时间必须早于结束时间。
- 固定样本的时间范围和随机种子，验收时不使用持续变化的“现在”。

### C. 数据库环境与配置

- 优先使用项目 Compose 中单个 PostgreSQL 服务，或复用已有专用开发数据库。
- PostgreSQL 版本使用明确且当前可用的标签，记录实际版本，不使用无约束 `latest`。
- Day 3 不安装 pgvector、不导入向量依赖。
- 数据库凭据通过现有配置机制管理，只向 `.env.example` 写占位值；连接 URL 同样可能含密码，不打印完整 URL。
- 数据使用持久卷；绑定本机回环端口或容器内部网络，不开放公网数据库访问。
- Compose 健康检查仅表示数据库可接收连接，迁移仍需显式执行。
- 不以删除卷、清库、覆盖现有表解决连接或迁移问题。

若 Docker 或镜像获取受阻，按当前权限规则处理；独立推进模型、导入校验和离线测试。SQLite 可作为临时适配或测试工具，但不能据此声称 PostgreSQL 集成验收通过。不要无限排查环境而停止其他工作。

### D. SQLAlchemy 与迁移

- 轻量服务器、低并发场景优先采用同步 SQLAlchemy，会话生命周期明确；不因 FastAPI 使用异步接口就强制引入异步 ORM。
- Engine 和 Session 工厂集中管理，每个操作或请求使用独立会话，异常回滚并关闭连接。
- 模块导入时不建立外部连接，不因数据库不可达破坏原有纯存活接口。
- 使用 Alembic 管理首个迁移，检查自动生成结果后再应用；不要把应用启动时自动 `create_all()` 当作迁移方案。
- 初始索引可考虑 `(service, occurred_at)`，说明对应按服务和时间范围过滤。100 条样本不足以证明索引性能提升，不编造优化收益。
- 如果项目已有数据库和迁移历史，追加合理变更，不覆盖历史。

### E. 导入命令与重复策略

命令示意（最终以实际实现为准）：

```bash
python -m scripts.import_incidents --input data/incidents/sample_incidents.jsonl
```

要求：

- 支持显式输入文件路径，不硬编码个人绝对路径。
- 校验文件中所有记录，错误给出行号、字段与非敏感摘要。
- 对当天规模优先先全部校验、再单事务写入，避免坏数据导致半批导入。
- 同一文件重复导入不得产生新行。
- 推荐最小重复策略：相同 ID 且规范化后内容相同则跳过；相同 ID 但内容不同则报冲突并回滚，不静默覆盖。
- 检查单个输入文件内重复 ID，冲突规则与库内一致。
- 对小样本可先读取已有 ID 比较，再插入；数据库唯一约束仍必须存在。Day 3 不扩展为高并发导入平台。
- 输出读取数、新增数、跳过数与失败原因；失败返回非零退出码。
- 不修改源数据文件来掩盖导入错误。

### F. 查询与最小聚合

通过参数化 ORM / SQL 表达式实现：

1. 按服务和明确时间范围查询。
2. 获取过滤后的总数。
3. 按错误类型 `GROUP BY`，计数降序、类型名称升序。
4. 返回 Top K，类别少于 K 时返回实际类别数。
5. 空结果返回总数 0、空列表。

统计不要交给模型，也不要把全部记录返回后让 LLM 计算。百分比若实现，其分母为过滤后的总数，而非 Top K 数量之和。

只需通过函数、CLI 或现有合理入口验证，不为了展示数据库另建无必要 API。后续工具只能使用受限参数，不能直接获得任意数据库执行权限。
